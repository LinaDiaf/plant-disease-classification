# Plant Disease Classification

This project focuses on automatically **classifying plant diseases** from leaf images. 
The dataset is sourced from **Kaggle** and includes various plant types and disease categories.

## Objective
To develop a **deep learning model** capable of detecting plant diseases from images, 
helping farmers and researchers improve crop management and plant health monitoring.

## Technologies
- Python
- TensorFlow / Keras
- NumPy, Pandas
